# TurnOffMonitor Versión 1.0
App de monitoreo de temperaturas con apagado automático.

### Requisitos
- Windows 10/11
- .NET 10 Runtime
- WebView2 Runtime

### Características
- Monitoreo de CPU() y GPU en tiempo real
- Apagado automático al bajar del umbral configurado
- Interfaz retrowave

### Detalles a tomar en cuenta

Ejecutar "TurnOffMonitor.App.exe" para su uso

Su primera ejecución suele tardar un poco más de lo esperado

Soporte actual para temperaturas en:
- Procesadores AMD y
- Tarjetas gráficas NVIDIA
